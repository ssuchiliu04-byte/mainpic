二、內容呈現規劃與討論

A 排版一：產品 + 特色 Icon

為何將特色 Icon 去除文字？

Icon 理想上應具備識別辨識的功能。如果需要將文字一併排列才能解釋此 Icon，則表示該 Icon 單獨的語意強度不足。

解決方式：

僅使用辨識度高的直覺 Icon。需要文字解釋的部分，納入右側「文字規格資訊區」。

(懸停可放大檢視) 左：無文字版本 (採用) / 右：有文字版本 (較雜亂)

可使用的直覺性 Icon 範例

B 排版二：產品 + 容量

將產品及容量安排在同一側。由於產品版面區域大，消費者第一眼即能理解此產品所擁有的容量，再從右側規格細讀資訊。

優點分析

  • 釋放右側空間：將容量與產品放在一起，右側「文字規格資訊區」空間變大。
  • 強化數據呈現：可將 Icon + 文案放大使用，提高易讀性。

目前先使用「排版二」來做後續主圖排版的模擬

考量到產品的長度跟高度，上方排列 Icon 的效益不高（看不清楚及過小），也影響視覺瀏覽的動向。

具有品牌記憶力的主圖 可讀性高 流暢的視覺動線 修整 Icon

三、討論與調整

Q1. 關於視覺舒適度與競品分析

主圖排版應以「視覺舒適」及「重點瀏覽清晰」為主。如將所有特色都做為賣點強調，版面會過於凌亂。 競品常有畫面過於擁擠、銷售重點隨意擺放無瀏覽順序的問題。

結論： SP 在設計上應以「產品、規格(容量/速度/接頭)」為主，其餘輔助資訊可簡化或刪除。

主圖修正

銷售主圖的用意？

主圖到底是「轉換工具」，還是「規格說明書縮圖」

我們設計目的是希望能讓消費者在看到這張圖 0.3–1 秒 內選擇停留，並理解此品項 願意再深入理解，倘若產品資訊過多，是有可能增加閱讀負擔也無法嶄露專業性而跳離網頁。

>>> 人在短時間內能處理的資訊量有限 <<<

目前情況

1. 各種產品方向及圖示隨意配置

雜亂的視覺讓消費者難以快速掃描與建立品牌印象，降低信任感

2. 資訊沒有層級，全部都在「大」

當所有資訊都被視為主角，消費者瀏覽完仍無法記住任何關鍵賣點，視覺負擔上升、轉換下降

3. 同系列產品排法不一致

系列視覺缺乏一致性，消費者難以快速辨識差異與規格配置，降低比較效率與系列辨識度

4. 產品與規格同時搶主角

版面同時放大多個重點導致擁擠，視覺動線混亂，消費者難以在短時間內抓到第一優先資訊
